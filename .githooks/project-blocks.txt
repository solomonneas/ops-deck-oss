# One PCRE alternative per non-blank, non-comment line. The pre-commit and
# commit-msg hooks, scripts/pr-create.sh, and CI join these with '|' to form
# the layer-2 block regex. Blank and # lines are ignored.
#
# Identifying tokens (personal hostnames, home LAN ranges, school refs,
# personal handles) do NOT live in this tracked file: a published blocklist
# leaks the very tokens it blocks. They live in two places instead:
#   - .githooks/project-blocks.local.txt (untracked, gitignored) - read by
#     the hooks and scripts/pr-create.sh alongside this file
#   - the PROJECT_BLOCKS_EXTRA repo Actions secret - read by CI
# Keep those two in sync when adding or changing tokens.
#
# Only generic, non-identifying patterns belong in this tracked file.
